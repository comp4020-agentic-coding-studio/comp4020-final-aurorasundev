## 视觉核对结果与实施边界

- 8 张图均保持浅暖灰、空白纸团、炭灰控件、衬线字标和简洁布局。
- 首页只有写作入口与 README 链接；写作只有取消/投掷；阅读只有关闭。
- 没有恢复码、见证数字、焚烧、举报、Keep/Release 或个人历史界面。
- README 中提及后续功能只是说明未来范围，不代表当前功能。
- 图片的纸边、折痕与光照是视觉目标；真实动画和模型应复用指定 demo，不把生成 PNG 用作交互界面。
- 生成图存在自然材质明暗变化。Claude 用主计划 tokens 为起点，按参考整体校验；不把阴影颜色误取为页面背景。
- 对话框背景虚化不是本周必做后处理；可用半透明遮罩与交互锁定实现弱化。
- 桌面图约 16:9，手机图约 390:844；最终课程检查仍是 1920×1080 和 390×844。
- 纸团位置允许随机；文字、按钮、页眉与页面结构按主计划和对应图片保持一致。
- 桌面与手机写作标题为衬线，正文和按钮为 sans-serif。
- 没有浏览器实际运行或部署证据；完成实现后另行进行功能和视觉对照。
